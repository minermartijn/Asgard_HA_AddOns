# Icon Placeholder

This add-on uses the Material Design Icon (MDI) `mdi:api` specified in config.yaml.

For a custom icon, you can add:
- `icon.png` (96x96 pixels)
- `logo.png` (256x256 pixels)

Both should be placed in the root of the add-on directory.

The icon should represent:
- MCP (Model Context Protocol)
- Home Assistant integration
- API/connectivity

Suggested design elements:
- Home Assistant logo/colors
- Network/API symbols
- Protocol/connection indicators
